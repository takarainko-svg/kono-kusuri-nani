「この薬、なに？」PWA v1.0

このフォルダの中身を HTTPS 対応の静的ホスティングへそのまま配置すると、
スマートフォンのホーム画面からアプリのように起動できます。

iPhone / iPad:
Safariで公開URLを開く → 共有 → 「ホーム画面に追加」

Android / Chrome:
公開URLを開く → ブラウザメニュー → 「アプリをインストール」または「ホーム画面に追加」

重要:
PWAのインストール機能やオフライン機能は、原則としてHTTPS公開が必要です。
端末にindex.htmlを保存して直接開くだけでは、正式なPWAとしては動きません。

内容:
- 試作版のUI・薬剤5剤を継承
- ホーム画面追加用マニフェスト
- アプリアイコン
- standalone表示
- Service Workerによるアプリ本体のキャッシュ
